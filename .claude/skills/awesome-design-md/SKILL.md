# Awesome DESIGN.md

Source: VoltAgent/awesome-design-md (MIT). Each folder in `design-md/<site>/` contains a
`DESIGN.md`: a plain-text design system (colors, typography, spacing, components, rules)
that describes the visual language of that website.

## How to use

1. List the available styles: `ls .claude/skills/awesome-design-md/design-md/`.
2. Pick the one(s) that fit the brief. For a trustworthy local service business, good
   references are e.g. `airbnb`, `stripe`, `wise`, `intercom`, `notion`, `cal`.
3. Read that `DESIGN.md` fully and apply its tokens and rules to the UI you build.
4. Use it as **inspiration for the design language only** — never copy another brand's
   logo, name or trademarked assets, and keep the project's own brand colors and identity
   unless the user explicitly asks otherwise.
